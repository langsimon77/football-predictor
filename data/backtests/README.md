# Backtest predictions

Our own walk-forward predictions, kept because GitHub deletes workflow artifacts after 90 days and Phase 4 (stacking and calibration) needs them.

| File | Contents | Source |
|---|---|---|
| `dc_bayes_v1_walkforward_2021_2025.parquet` | 3,800 predictions of `dc_bayes_v1` (shots on target, NumPyro), 2021/22 to 2025/26, both leagues. Home, draw, away, over 2.5, BTTS, expected goals, 80% intervals, and the full 11 x 11 scoreline table per match. | GitHub Actions runs 36184624695 (2021/22, 2022/23) and 36184636547 (2023/24 to 2025/26), 25 Sep 2026 |
| `dc_bayes_v1_walkforward_2021_2025_fits.parquet` | One row per weekly fit: time, diagnostics, pass or fail. 345 fits, all passed. | Same runs |

Each prediction was made at the daily run that would have locked it, from a fit made at or before that time on results known by then.
| `cards_nb_walkforward_2021_2025.parquet` | 3,800 predictions of `cards_nb_v1`: expected total yellows, over 3.5, 4.5, 5.5, the full distribution of the total (0 to 16), whether the EPL referee was known at lock. | GitHub runs 36188267315 (tuning) and 36191021061 (test), 25 Sep 2026 |
| `corners_total_poisson_walkforward_2021_2025.parquet` | 3,800 predictions of `corners_total_poisson_v1`: expected total and per-team corners, over 8.5 to 11.5, the full distribution of the total (0 to 30). | GitHub runs 36190976694 (tuning) and 36192216819 (test), 25 Sep 2026 |
| `*_fits.parquet` | One row per weekly fit with diagnostics and, for negative binomial models, the dispersion estimate. | Same runs |
| `challengers_walkforward_2021_2025.parquet` | 15,200 predictions (3,800 each) of the four Phase 4 challengers: ordered logit, multinomial (C 0.01), Random Forest (depth 6, leaf 50), XGBoost (depth 2, 150 trees). Home, draw, away; refit date and training size per row. Settings chosen by time-ordered cross-validation on 2017/18 to 2020/21 only; refitted at the first lock of every month. | GitHub run 36195202742, 26 Sep 2026 |
| `challengers_walkforward_2021_2025_cv.parquet` | Cross-validation log loss for every setting tried. | Same run |
| `dc_bayes_v1_walkforward_2018_2020.parquet` | 2,280 predictions of `dc_bayes_v1` (same code and settings), 2018/19 to 2020/21, both leagues: the replication seasons of the October 2026 check-up. Caveat: the promoted-club prior is estimated on 2017/18 to 2020/21, so promoted clubs' forecasts here are slightly too good. | GitHub run 37909076802, 9 Oct 2026 |
| `dc_bayes_v1_walkforward_2018_2020_fits.parquet` | 196 weekly fits, all passed (17 needed the retry). | Same run |
| `fast_walkforward_2021_2025.parquet` | 3,800 predictions of Elo, fast Dixon-Coles and league base rates (1,100 days), 2021/22 to 2025/26, EPL and La Liga, refitted at every lock. Equal to the Elo and Dixon-Coles columns of `baselines_2021_2025.parquet`. | `fp.evaluate.backtest.run`, run on this Mac 12 Oct 2026 |
| `trial/` | The same walk-forward files for Serie A and Ligue 1 (on trial, `fp.leagues`), 2021/22 to 2025/26: `fast_`, `dc_bayes_v1_`, `corners_total_poisson_`, `cards_nb_`, `challengers_` (with fits and cross-validation files). Scored by `scripts/backtest_trial.py`. | Fast: this Mac. Others: GitHub runs 38310065127 (goals), 38310068965 (corners), 38310073216 (yellows), 38310077149 (challengers), 12 Oct 2026 |
| `dc_reference_walkforward_2021_2025.parquet` | 3,800 walk-forward forecasts of the reference Dixon-Coles model (`fp.models.dc_reference`, decay 0.0018, refitted at every lock on 1,100 days), EPL and La Liga, 2021/22 to 2025/26, with the existing model's and `dc_mle_v0`'s forecasts and the outcome; `status` says why a match has no `dc_ref` forecast (unseen club). | `scripts/compare_dc_reference.py test`, this Mac, 14 Oct 2026 |
| `cards_nb_epl_2023_2025_referee_as_now.parquet`, `..._referee_always.parquet` | 1,140 EPL `cards_nb_v1` walk-forward forecasts each, 2023/24 to 2025/26: referee used only when known at lock (as live), and every referee known (the value of a late update). | `fp.evaluate.backtest_counts cards EPL 2023 2024 2025 [--referee-always]`, this Mac, 14 Oct 2026 |
| `ucl/club_dc_walkforward_2021_2025.parquet` | 753 walk-forward forecasts of the Champions League model `club_dc_v1` (`fp.models.club_dc`), every Champions League match of 2021/22 to 2025/26 with a result, each at its lock time: home, draw, away, over 1.5, 2.5 and 3.5 goals and expected goals; the same model on European results only; Elo with its ordered-logit curve; Champions League base rates. `..._fits.parquet`: one row per fit (154, all converged). Scored by `scripts/backtest_ucl.py`; margins by `scripts/ucl_safety.py`. | This Mac, 20 Oct 2026 |
