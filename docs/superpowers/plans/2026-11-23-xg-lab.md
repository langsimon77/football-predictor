# xG Test, xG Panel and Model Lab Clean-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run two hidden xG versions of the goals model as pre-registered, show their progress (count and average only) in a Model lab panel, and make the live Model Lab page easier to read.

**Architecture:** `xg_mode` is a new setting on the existing Bayesian Dixon-Coles model. The daily and trial pipelines lock two extra shadow rows per match. A new script turns ledgers plus committed part A results into `xg_test.json`, which travels to the page on branch `lab-data`. Page changes are patch scripts applied to the live page, never a rebuild.

**Tech Stack:** Python 3.12, PyMC + NumPyro, pandas, pytest, GitHub Actions; plain JavaScript in one HTML artifact.

**Spec:** `docs/superpowers/specs/2026-11-23-xg-lab-design.md` and `data/audit/preregistration_xg_2026_11.md` (both bind every task).

## Global Constraints

- Model names, exact: `dc_bayes_xg_joint_v1`, `dc_bayes_xg_blend_v1`. Control: `dc_bayes_v1_noshape`.
- Both arms = live `BAYES_PARAMS` (`use_sot=True`, `sampler="numpyro"`, xi 0.002, window 1,100 days, seed 2026) plus `xg_mode`.
- Joint priors: `mu_x ~ N(0.3, 0.5)`, `home_x ~ N(0.1, 0.2)`, `c_att ~ N(1, 0.5)`, `c_def ~ N(1, 0.5)`. xG kernel weight 1. Blend weight 0.5. Dixon-Coles tau uses the real score.
- Shadow rows: same lock time and team-news scale as the control, no shape fix, flags include `"shadow"`. Never published.
- Fit gate: R-hat < 1.01, bulk ESS > 400, no divergences. A failed arm locks nothing that run.
- Shadows never block the published forecast.
- `xg_test.json` holds no interval, bootstrap, pass or fail field.
- Page text: no em or en dashes. Panel uses one neutral colour for both arms.
- Never overwrite the live page from football-lab source. Patches assert each target string occurs once.
- Branch work only; Lang merges. Wait for CI before merge.

## Review Focus

1. A season where only some matches have xG (late data rows): those rows add nothing to the xG term, goals still count. Test in Task 1.
2. One arm fails its fit gate but the other passes: only the passing arm locks; the paired report drops that match from both and counts it. Tests in Tasks 3 and 5.
3. `xg_test.json` missing or a league with 0 matches: the panel shows the plain "not started" or "no matches yet" text, no error, no `NaN`. Test in Task 6.
4. Team news scaling present: xG rows use the same scale as the control row. Test in Task 3.
5. Phone width (375 px) and dark mode: panel and clean-up have no horizontal scroll and readable contrast. Browser check in Tasks 6 and 7.
